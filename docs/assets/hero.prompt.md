# Subagent Hub Hero prompt

Create an original, polished open-source developer project hero banner for **Subagent Hub**, a companion to official DeepSeek Harness subagents.

Use a wide horizontal composition. All important text and artwork must fit within the central horizontal band, with quiet dark padding in the top and bottom 20 percent so the image can later be cropped to a wide GitHub README banner.

The background is nearly black charcoal with restrained mint teal and desaturated icy-blue accents. On the left, typeset the exact title **Subagent Hub** in a confident, modern, highly readable sans-serif. Below it, the exact supporting line **Named roles. Clear routes. Visible models.** and the smaller line **A companion to official DSH subagents**. Keep the hierarchy clear and the text crisp.

On the right, create one sparse, elegant hub-and-spoke routing illustration: a central graphite rounded-square core connected by fine luminous routes to three distinct agent nodes. Give one route a minimal checkpoint bracket to suggest a route guard. Mostly clean vector-like geometry, very subtle glass depth, soft local light, and an almost invisible technical grid. Plenty of negative space. Precise and purposeful, like a carefully designed engineering project rather than generic AI stock art.

No dashboard, browser, fake UI, robots, people, mascots, existing company logos, excessive neon, dense circuit-board patterns, particles, extra text, or watermark.
